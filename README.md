## About the Project
Development of a corporate website and landing page for **V&P Group** (Poland) — from landing page design to backend contact form integration.

## Features
- Landing page (HTML/CSS/JS) with responsive layout
- Django backend with a contact form
- Client-side form validation with JavaScript
- Automatic forwarding of form submissions to Telegram via an IMAP script
- Deployment on cPanel/HostIQ
